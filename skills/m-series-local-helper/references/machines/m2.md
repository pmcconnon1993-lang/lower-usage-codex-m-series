# M2 family

Checked 2026-10-22. Recognized variants: **M2, M2 Pro, M2 Max, M2 Ultra**. Ask for exact RAM, product and GPU variant before choosing.

Verified product examples: [M2 MacBook Air](https://support.apple.com/en-us/111867) offers 8/16/24 GB. [M2 Pro and Max](https://www.apple.com/newsroom/2023/01/apple-unveils-m2-pro-and-m2-max-next-generation-chips-for-next-level-workflows/) support up to 32 GB and 96 GB respectively. [2023 Mac Studio](https://support.apple.com/en-us/111835) lists M2 Max 32/64 GB, or 96 GB with its 38-core GPU; M2 Ultra 64/128/192 GB. Do not combine these into invented options for a different product.

Choose the catalog's RAM tier: narrow 2B work at 8 GB; 4B at 16-24 GB; 9B at 32 GB; evaluate sparse 35B models on larger machines with headroom. The helper still needs Codex review.

oMLX/MLX is the default runtime path. Official Splash does not support M1/M2 GPUs. The [unofficial port](https://github.com/paperniuk/splash/releases/tag/1.3.2-m1.2) has specific M2 Max evidence, including changes to cached prompt appends, but that does not validate every M2, model or RAM size. If the user chooses the port, qualify it directly without requiring an unrelated runtime installation first. A claim that it outperforms oMLX needs a working matched baseline for comparison.

An existing second Mac may run a bounded job independently, but its RAM is not pooled with the controller's RAM. Remote helpers need their own readiness, model, storage and authenticated private endpoint checks. Do not install distributed inference merely because two Macs exist. See [upstream sources](../upstream-sources.md).
