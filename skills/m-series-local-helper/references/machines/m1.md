# M1 family

Checked 2026-10-22. Recognized variants: **M1, M1 Pro, M1 Max, M1 Ultra**. These names are verified hardware; recommendations remain candidates until the local acceptance test passes.

Ask for the exact Mac, RAM and macOS, or inspect them with permission. Product examples: [M1 MacBook Air](https://support.apple.com/en-us/111883) has 8/16 GB; [2021 MacBook Pro](https://support.apple.com/en-us/111901) has M1 Pro 16/32 GB or M1 Max 32/64 GB; [2022 Mac Studio](https://support.apple.com/en-us/111900) has M1 Max 32/64 GB or M1 Ultra 64/128 GB. This is product evidence, not every possible chip/RAM combination.

Use the catalog's RAM tier, then reduce it if other work consumes headroom. An 8 GB machine starts with the 2B MLX candidate for narrow extraction; a 16 GB machine can assess the 4B candidate; a 32 GB model can assess 9B. Larger Max/Ultra machines can assess Qwen3.6-35B according to measured memory and required quality. More RAM does not eliminate prefill or decode cost.

Default to oMLX's MLX engine when its OS requirements pass, or the bounded MLX-LM fallback. **Official Splash requires M3+**. The [M1/M2 community port](https://github.com/paperniuk/splash) is optional and unofficial. Its [1.3.2-m1.2 release](https://github.com/paperniuk/splash/releases/tag/1.3.2-m1.2) did not test sub-64-GB Macs; do not promise it works on an 8/16-GB M1.

Start one job, a short prompt and modest output. Check tool arguments, useful task completion, memory pressure and responsiveness. Do not transfer M5 benchmark speeds to this family. Runtime requirements and source dates: [upstream sources](../upstream-sources.md).
