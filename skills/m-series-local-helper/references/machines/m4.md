# M4 family

Checked 2026-10-22. Recognized variants: **M4, M4 Pro, M4 Max**. An M4 Ultra is not verified by this catalog; an unexpected label requires a source refresh.

[Apple's M4 family announcement](https://www.apple.com/newsroom/2024/10/apple-introduces-m4-pro-and-m4-max/) documents maxima of 32 GB for M4, 64 GB for M4 Pro and 128 GB for M4 Max. These are family capability limits, not every product's purchasable configuration. The [2025 Mac Studio](https://support.apple.com/en-us/122211) lists M4 Max 36 GB, with 48/64/128 GB for its 16-core-CPU/40-core-GPU option. Ask the user or inspect the actual machine.

Use the RAM tier and current headroom to select one candidate. At 16-24 GB start with the 4B MLX helper, at 32-36 GB assess 9B, at 48-64 GB assess Qwen3.6-35B 4-bit, and at 96+ GB assess its 8-bit version. A larger model is worthwhile only if it improves accepted task results enough to justify its latency and memory.

oMLX/MLX is the ordinary small-model route. Official Splash can be assessed for its supported large Qwen targets after the macOS 26.4+ and memory gates pass. Keep Codex's main model unchanged; all conclusions from the helper need independent checking. Measure whole-task time and context reuse, not just peak generation speed.
