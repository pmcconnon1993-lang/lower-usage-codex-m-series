# M5 family

Checked 2026-10-22. Recognized variants: **M5, M5 Pro, M5 Max, M5 Ultra**. M5 Ultra is publicly documented hardware, not a future placeholder.

Verified product examples: [M5 MacBook Air](https://support.apple.com/en-us/126320) has 16/24/32 GB. [M5 Pro Mac mini](https://support.apple.com/en-us/128108) has 24/48/64 GB. [M5 Mac Studio](https://support.apple.com/en-asia/128107) lists Max 36 GB and 48/64/128 GB with its 40-core GPU; Ultra 96 GB and 256/512 GB with its 80-core GPU. Verify product, GPU and actual RAM before choosing.

Small M5 configurations still use the small/mid MLX candidates. M5 Max is not automatically the same tier as M5 Ultra. For 48-64 GB, assess Qwen3.6-35B-A3B 4-bit with sufficient headroom; for 96+ GB, assess the 8-bit target. Official Splash requires macOS 26.4+ and an exact supported target/draft pair.

The repository's high-memory seed preserves the user's chosen **Qwen3.6-35B-A3B 8-bit** helper through oMLX-managed Splash/DFlash2. Its rationale is sparse active computation, retained weight precision, model-specific Metal execution and state reuse. It is a starting point for comparable bounded work, not a universal benchmark victory. Keep the separate older GGUF memory-review proof distinct from the current helper configuration.

On a machine matching that seed, preserve BF16 KV, 32K context, a 64-GiB Splash ceiling, 8-GiB SSD cache and one job initially until a controlled test justifies change. These are seed configuration choices, not defaults for every M5. Never copy a private user's filesystem paths or credentials.

Run a real selected-file task and tool round trip, verify its claims, then measure accepted task latency and desktop headroom. See [upstream sources](../upstream-sources.md).
