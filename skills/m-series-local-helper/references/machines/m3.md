# M3 family

Checked 2026-10-22. Recognized variants: **M3, M3 Pro, M3 Max, M3 Ultra**. RAM and product matter more than the generation number alone.

Product examples: [base M3 MacBook Pro](https://support.apple.com/en-us/117735) lists 8/16/24 GB. [M3 Pro/Max MacBook Pro](https://support.apple.com/en-us/117736) has Pro 18/36 GB; Max with the 14-core CPU has 36/96 GB, while the 16-core CPU supports 48/64/128 GB. Use the actual machine rather than interpreting this as interchangeable options.

[M3 Ultra's launch announcement](https://www.apple.com/newsroom/2025/03/apple-reveals-m3-ultra-taking-apple-silicon-to-a-new-extreme/) documents support beyond half a terabyte. The current [2025 Studio support page](https://support.apple.com/en-us/122211) lists a narrower 96/256-GB selection. Current store/spec selections are not proof that an already-owned higher-memory configuration cannot exist; verify actual hardware.

Use oMLX/MLX for small candidates. **Official Splash can be evaluated on M3+ with macOS 26.4+**, a supported target and its matching draft, and enough measured headroom. Do not select Splash for the small Qwen3.5 models by family-name similarity: its listed targets are model-specific.

The catalog begins conservatively: 4B for 18 GB, 9B for 36 GB, 35B 4-bit for 48/64 GB, and 35B 8-bit for high-memory configurations. These are project starting points, not measured winners. Test fresh and reused prompts, task correctness and a real tool round trip. See [upstream sources](../upstream-sources.md).
